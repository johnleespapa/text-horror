# 해월동의 구멍 (텍스트 호러 프로토타입)

바닷가 아파트 단지 해월동에서 사라진 동생 수아를 찾는 한국어 텍스트 어드벤처. 이미지 없이 글로만 진행됩니다.

플레이: https://johnleespapa.github.io/text-horror/

## 하는 법
- 방향 버튼 또는 방향키/WASD로 5x5 지도를 한 칸씩 이동. 숫자키 1~9로 선택지 선택.
- 스탯: HP, 공격력, 이성. 이성이 50 아래면 글자가 일그러지고, 35 아래면 붉은 환각 선택지가 섞입니다.
- 판정: d20 + 보정 ≥ DC (힘=공격력, 정신=이성·부적, 관찰=단서·손전등). 선택지에 DC와 성공 확률이 표시됩니다.
- 장소에 들어서면 확률적으로 랜덤 사건(전역/장소 전용)이 일어납니다. 선택에 따라 증상·아이템·플래그가 생기고 이후 사건과 엔딩에 영향을 줍니다.
- 턴 70이 되면 만조로 게임 오버. 진행은 자동 저장, 엔딩은 수집 기록됩니다.

## 엔딩 (13종, 스포일러)
1. 썰물 (진실) — 단서 4개 이상 + 노래를 거꾸로 불러 성공
2. 반쪽의 바다 — 노래 성공, 단서 부족 (수아 잃음)
3. 대신 들어간 자리 — 수아 대신 구멍에 들어감 (희생)
4. 둘만의 새벽 — 수아를 억지로 끌어내 탈출
5. 막차 — 턴 8 이후 정류장에서 혼자 탈출
6. 작은 손 — 미나를 데리고 탈출
7. 부르는 자 — 부름에 대답하거나 노래 실패 (공포의 일부가 됨)
8. 나선의 눈 — 이성 0
9. 내 모양의 구멍 — 내 모양 구멍을 본 뒤 이성 0
10. 차가운 바닥 — HP 0
11. 깊은 물 — 수아 끌어내기 실패
12. 배신의 대가 — 박 씨 열쇠를 훔친 뒤 동굴에서 응징
13. 만조 — 시간 초과
